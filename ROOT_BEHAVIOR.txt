ROOT BEHAVIOR
=============
Opening the repository/domain root loads the document viewer in blank mode.
It does NOT select any mapped document and does NOT expose document data.

Root example:
  https://example.com/repository/

Document example:
  https://example.com/repository/files-portal/TOKEN

Implementation note:
The root page loads the viewer internally with ?__blank=1. document-router.js now captures
that flag once at startup, before Angular can rewrite the query string. Therefore root mode
stays blank for the entire viewer session.
